UMAMUSUME IMAGE ASSETS
======================

Please add the following images to this directory:

1. haru-urara.png
   - A transparent PNG of Haru Urara character
   - Recommended size: 400-600px width
   - Should have transparent background
   - You can find character art from:
     * Umamusume Pretty Derby Wiki
     * Official game assets
     * Fan art sites (with proper attribution)

2. umamusume-bg.jpg
   - A background image from the game
   - Recommended size: 1920x1080px or larger
   - Can be a race track, training grounds, or game scene
   - JPG or PNG format

Temporary placeholders will be created if these files are missing.
