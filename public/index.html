Quick Setup

For Claude Web (claude.ai):

  1. Go to claude.ai and open any conversation
  2. Click the MCP icon (puzzle piece) in the input area
  3. Click "Add Server"
  4. Enter the MCP discovery URL below
https://umamusume.training

Note: The server will connect automatically. Make sure you're using the HTTPS URL above.

For Claude Desktop:

  1. Open Claude Desktop settings
  2. Navigate to Developer → Edit Config
  3. Add the server configuration to claude_desktop_config.json:
{ "mcpServers": { "umamusume-trainer": { "url": "https://umamusume.training" } } }
  1. Restart Claude Desktop to activate the connection
